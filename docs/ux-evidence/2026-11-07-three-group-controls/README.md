# 点播三组控制栏：本地验证

按用户指定的顺序实现主栏，替代之前的七按钮／更多菜单方案：

| 左侧 | 中间 | 右侧 |
|---|---|---|
| 点赞、投币、收藏、稍后再看 | 上一个、播放／暂停、下一个 | 评论、设置 |

三组留白，播放按钮居中，首次打开焦点在播放按钮。互动计数与短按点赞、长按三连留在主层；画质、倍速、字幕、弹幕开关、弹幕设置及关注 UP 主放入设置。子菜单返回设置原条目，再返回主栏设置。设置焦点按功能 ID 保存，字幕异步到达不会改变当前操作目标。

上一个／下一个遵循显式列表、分 P、合集或番剧顺序，不首尾循环，切换从零开始。普通视频没有上一个，下一个使用不同的相关推荐；不可用项由方向键跳过。分页失败可重试，离开播放器后迟到响应无效；手动切换与片尾自动连播共用互斥状态。

保留两排正常尺寸的视频卡片、展开／收起和逐排滚动动画、字幕避让及粉丝数同步淡出。720p 加评论栏时保留三组图标与计数，完整动作名称显示在固定的焦点说明行；极长数字允许省略，说明行保留完整数值。

## 边界

本轮仅本地验证。浏览器媒体解码、API 与账号响应由隔离夹具控制，非 Vite 网络请求被拦截，没有操作电视或真实账号。动画采样及六倍 CPU 降速检查不等于电视实际帧率；旧 CSS 降级和 ES2016 解析也不等于真实旧版 webOS 验收。`test-sim.mjs` 已迁移按钮顺序和设置入口并通过语法检查，没有执行真实账号 sim。没有安装、发布或更新 Homebrew。
