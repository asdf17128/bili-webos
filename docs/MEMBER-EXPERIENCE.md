# 会员身份与自动最高画质

自 2.4.0 起提供。前期测试包记录保留原版本标识，正式包验证见 [发布记录](RELEASE-2.4.0.md)。

## 使用方式

默认使用「自动 · 最高可用」。播放器请求完整画质列表，再从账号有权限、片源提供、电视能够支持的表示层中选择最高档；4K 电视继续排除 8K，不用高码率冒充更高画质。杜比检测、解码回退和高级音轨选择沿用已有保护。

播放时打开清晰度菜单，可以选具体档位，也可以切回「自动 · 最高可用」。手动选择成功后记住该档位；失败时保留原流和偏好。自动模式不会把某支视频降级后的实际档位保存成长期偏好，换视频仍重新选择。倍速返回正常播放也不会改变画质模式。

旧版设置会把默认 1080P 一起写入，无法区分默认值与主动选择。因此未带手动标记的旧 1080P 设置迁移为自动；其他旧档位继续保留。新版手选 1080P 会明确记录为手动，不再被迁移。

侧栏展开后与「我的」页显示有效「大会员」或「年度大会员」。会员状态来自登录接口，不依据 Cookie 是否存在或清晰度菜单的档位标签推断；未登录、失效或已到期不显示有效标识。

## Nerd 信息

设置 → Nerd 信息，默认关闭。打开后点播与直播显示独立技术面板；普通播放栏不再显示 AAC 等音轨标签。下载统计计入本次播放器实例已完成的媒体请求（包含音视频初始化段与重试完成的数据），速率按最近采样周期计算，并非网卡总流量。原生直播无法读取的字段显示「—」。关闭时不挂载面板、不运行采样计时器。

## 音轨和范围

视频与音轨独立选择：优先设备支持的 E-AC-3，再 FLAC、AAC；加载失败时按既有策略回退。最高可用不代表每个片源都有杜比音轨，也不代表已确认外接音响输出 Atmos。

Links《和李现，攀登人生第一座雪山》的实测接口仅提供 AAC，所选约 189 kbps 已是最高；另一支提供 E-AC-3 的杜比演示片可自动选到约 1.02 Mbps。[音轨源对照](ux-evidence/2026-10-14-audio-selection/results.json)。

本轮没有新增会员内容频道，没有修改会员权限或增加第三方会员代理。自动最高画质仍可能受网络吞吐限制；它不是根据带宽持续变档的自适应模式。

### LG C4 真机结果

安装包 SHA256 与实际加载的 JS、服务文件逐项匹配。新包专项 6/6（含恢复状态）：有效会员标识；Links 自动 qn126 / 3840×2160 / `dvh1.08.07` + AAC；遥控手动 qn80 / 1920×1080；遥控返回自动后恢复 qn126；换到杜比影院演示片后自动 qn126 / 3996×2160 / `dvh1.05.07` + `ec-3`，媒体时间与解码计数增长；恢复原观看并启用自动模式。

首次工具在 Shaka load 刚返回、readyState=0 时立即采样，误把尚未准备好的尺寸 0 判成切档失败，原始结果已保留。调整为等待真实媒体 ready、尺寸和时间推进后，使用相同包复验通过。未为通过测试修改播放器代码。此项证明短时播放与切换，不代表面板徽标、音响 Atmos 输出或新包长时稳定性全部通过。
