# 2.6.0 legacyfix.5 — 播放中操作响应测试

- 减少播放过程中进度条和后台进度同步的重复更新。
- 调整控制栏刷新方式，继续改善播放时的按钮切换和快进体验。
- 暂停时停止无用的进度轮询，保留暂停后的拖动、继续播放与推荐区动画。
- 网络诊断补充播放／暂停时的控制栏响应数据，方便继续定位间歇卡顿。

这是独立测试包，实际响应仍需原设备验证，不进入 Homebrew 或正式版自动更新。

## 安装与复测

下载 Assets 中带 `legacyfix.5` 的 IPK 覆盖安装，无需退出账号。设置 → 关于确认 **2.6.0 legacyfix.5**。

请与 legacyfix.4 对比同一视频、画质和弹幕设置：

1. 播放时，约半秒一次短按左右键，再长按 3–5 秒，观察按钮切换是否仍间歇停顿。
2. 暂停后重复操作，再恢复播放，比较差异。
3. 试一次长按快进、返回取消，再试一次松开后跳转。

若仍卡顿，在这组播放／暂停操作之后直接返回设置 → 网络诊断，生成报告并贴回原 issue。请先不要换片或重启，以保留这次操作的诊断。新版报告中的 `controls-playing` 和 `controls-paused` 行可帮助进一步排查；没有某一行也请原样反馈。

无需重复测试登录。需要回退可覆盖安装 legacyfix.4。
