# v2.2.1 — 连播可停止，循环可选择

修复 #41：关闭自动连播后，收藏夹、稍后再看、分 P、合集及跨页列表仍会自动跳到下一条。失效视频也不会在停止模式下自行跳过。

设置 → 播放与显示 → **播放结束后**，现在提供三个选项：

- **自动连播**：维持现有的列表顺序播放和相关推荐倒计时。
- **播完停止**：结束后停留在播放器，可手动重播或选择下一条。
- **单集循环**：重复当前视频 / 当前分 P，可随时用遥控器暂停或退出。

升级前关闭连播的用户会继续使用“播完停止”，不会自动变成循环播放。循环失败时保留手动重播入口；列表分页失败或播放期间退出，不会被迟到的结果强行带走。“看完移出稍后再看”保持独立，每次打开视频最多执行一次，避免循环时重复删除请求。

感谢 @SSSS-VIII 在 PR #42 中定位收藏夹与分 P 绕过设置的问题。本版在该修复思路上适配新版播放器，将停止与循环设计为独立选项，并补齐回归验证。PR #17 的特定杜比 4K120 帧变换不在本次更新范围内。

安装包、`version.json` 与 Homebrew manifest 一起发布。Homebrew 商店目录需要等待上游同步。

最新社区实测：[#34 的 LG C9 用户](https://github.com/asdf17128/bili-webos/issues/34#issuecomment-6013025918) 确认 2.2.0 的直播、搜索、DLNA 和弹幕可用，但报告首次出画面变慢、弹幕有卡顿。该报告的网络诊断正常，尚不足以定位起播耗时来源；这两项继续跟踪，**不属于 2.2.1 已修复范围**。旧大会员账号仍待对方复测。

## English

Fixes #41: disabling autoplay now applies to favorites, Watch Later, multipart videos, collections, paginated lists and unavailable-video skipping.

**Settings → When playback ends** offers **Play next automatically**, **Stop after this video**, and **Repeat current video**. Existing autoplay-off users keep the stop behavior. Repeat is explicitly selected, remains pausable, and falls back to manual replay if restarting fails. Late playlist responses cannot navigate after leaving playback.

Thanks to @SSSS-VIII for identifying the missing playlist/part gate in PR #42. The fix was adapted to the current player and expanded with independent stop/repeat choices and regression coverage.
