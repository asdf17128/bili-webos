# 2.6.0 legacyfix.1 — 旧电视播放测试包

针对 #34 中旧电视升级 2.6.0 后仍提示账号风控、偶尔才能播放的问题，修复一处可能阻止自动恢复的兼容性问题。

这是独立测试包，不进入 Homebrew 或正式版自动更新。尚需报告者的原设备确认，不代表已解决所有账号播放限制。

## 安装与复测

1. 下载本页 Assets 中带 `legacyfix.1` 的 IPK，用 webOS Dev Manager 覆盖安装，无需卸载或退出账号。
2. 设置 → 关于确认显示 **2.6.0 legacyfix.1**。
3. 保持登录，直接重试一条原先失败的视频；无需清缓存或重建设备标识。
4. 若仍失败，请先不要换片或重启，到设置 → 网络诊断生成报告，附视频 BV、电视型号和 webOS 版本。请保留 `activation`、`identity-fields`、`previous-recovery` 和 `attempt` 行（没有的行无需补）。不需要 Cookie 或登录二维码。
5. 若恢复，请反馈能否正常起播和持续播放，也请留意原先偶尔成功的视频是否变稳定。

如需回退，可覆盖安装 v2.6.0 正式包。

## 验证范围

- 本地完整回归通过（`tools/verify.sh --no-tv`）。
- 缺少 Intl、时区与处理器信息的模拟通过；旧代码对照可复现。
- 自动恢复专项 8 个场景通过，包含旧设备恢复后重试取得视频流、失败、退出／切换账号、并发、诊断与写盘失败。
- 真实 Node 0.12.2／8.17.0 检查通过，生产包通过 Chrome 53 语法兼容检查。
- 安装包内服务文件和测试版本标识已核对。未在报告者的旧电视和账号上验证。
