# 2.4.1 验收记录

源码候选 `d49d78d`，后续仅文档与证据。范围为 #50、#51、#52 的取流风控、设备标识恢复与诊断误报。

## 修复与证据边界

#51 报告者保留同一电视 SESSDATA，仅替换 buvid3 / buvid4 / b_nut 后恢复播放。源码核对确认旧服务只初始化一次、退出登录保留标识。#50 和 #52 表现接近，但没有把三者的现场根因直接等同。

本版只对 api.bilibili.com 的 GET UGC/WBI/PGC playurl 中 -351、-352 或无视频流的 voucher 响应尝试恢复。每次请求最多重试一次，并发共享刷新，5 分钟冷却持久化，失败保留原标识和登录；新值从官方 SPI 响应获取，b_nut 采用 Set-Cookie，不伪造激活信息。设置可手动重置。已有视频流的 voucher 响应、地区/权限错误、POST 和无关主机不会自动刷新。

诊断保留原始 code、voucher 有无、是否有流，不导出 voucher 内容；缺少媒体地址时明确 CDN 未测试。播放器不会将只有 voucher 的 code=0 响应当作可播放。
