# YouTube 电视端控制栏参考核对（2026-10-23）

用户看过第一版本地预览后要求先研究真实 YouTube 电视 App 再调整。本轮范围仅为移除控制栏整块底板感；不新增功能，不改变推荐接口或遥控操作语义。此前工作树与截图保留。

## 已实际查看的来源

1. [YouTube 官方博客，2025-04-23](https://blog.youtube/news-and-events/happy-birthday-youtube-20/) 的 “YouTube on TV app redesign” 演示；[原始 MP4](https://storage.googleapis.com/gweb-uniblog-publish-prod/original_videos/Lofi-Girl_YT_Redesign.mp4)，1280×720、13.28 秒。已本地取 0/6/12 秒帧及时间序列查看。它是官方设计演示，不是本次实机验收。整个短片控制栏一直展开，中央显示暂停图标及白色圆形焦点；它没有展示遥控焦点移动、返回或推荐完全展开的操作。
2. [Android Authority 现场报道，2025-09-01](https://www.androidauthority.com/youtube-tv-new-ui-rolling-out-3593165/)，作者标明 Sony 43X8000H、Android TV 10。[已查看的实拍图](https://www.androidauthority.com/wp-content/uploads/2025/09/New-YouTube-TV-UI-on-Android-TV-scaled.jpg) 为暂停状态，中央是播放三角及白圆。实拍有面板、环境光与相机影响，不能反推精确 CSS alpha。
3. [YouTube 官方电视观看页改版公告，2025-12-11](https://support.google.com/youtube/thread/394085818/redesigned-youtube-watch-page-on-tvs?hl=en) 可核对名称和三组控件方向；当前正文提取不完整，不据此杜撰动态行为。

这些资料都指 YouTube 电视 App，不是付费直播订阅产品 YouTube TV，也不是手机或普通桌面播放器。它们不能证明每台设备、账号或 2026 年版本完全相同。

## 可观察的设计与当前差异

| 部位 | 参考中实际可见 | 本项目第一版与调整边界 |
|---|---|---|
| 背景 | 视频细节贯穿控件区域；底部柔和压暗，无整条矩形面板边界 | 第一版在 46px（720p 为30px）内升至72%黑，后续74%～82%，形成深灰平台；仅修正渐变和必要字形阴影 |
| 按钮 | 局部圆形/胶囊半透明底，中央播放/暂停焦点白圆 | 保留独立焦点和操作结构，不为仿制新增按钮或改键位 |
| 进度条 | 位于按钮上方、横贯大部分画面 | 保留现有位置、点击/遥控 seek 行为 |
| 标题和作者 | 标题在左上，下面是作者、观看数与时间；频道入口位于左下 | 不能把观看数说成粉丝数。用户已定 UP 粉丝数与现有标题布局保留，不扩大为全布局重排 |
| 推荐 | 最底部仅露出部分卡片 | 继续复用现有推荐及已完成 Down/Back 路径；资料未验证完整展开态，不声称逐项复刻 |
| 焦点 | 官方演示与实拍均有清晰独立焦点 | 单帧/短片不能证明所有遥控转移，按本项目既有测试回归 |

调整方向是去掉大片均匀深色底板，让内容透出。渐变参数是本项目的视觉取舍，不是从 YouTube 源码测得。字幕文字框、弹窗、错误状态和长按菜单有各自背景，不属于本次常态底板问题，保持现有语义。

## 本地落地

仅修改 `app/src/player/playerControls.css`：取消首段急升和72%～82%平台，改为跨控制区连续的0%、10%＠18%、24%＠40%、40%＠70%、58%＠底部压暗；720p共用同一平滑曲线。白字采用紧贴字形的阴影，元数据更亮，SVG图标增加轻阴影；普通按钮仍透明，焦点仍独立高亮。未加额外全屏遮罩、伪元素或层叠改动，未改字号/位置/遥控逻辑。

新增本地合成海面纹理与窗框场景，保存同一场景开关控制栏及修改前后截图，防止纯色背景无法说明视频穿透。实际观看新版截图可见纹理从画面延续至按钮、时间与推荐预览间隙；素材为测试SVG，不是真实解码视频。完整记录位于 [透明度回归证据](ux-evidence/2026-10-23-player-transparency/README.md)。
