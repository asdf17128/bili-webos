# 2.6.0 legacyfix.6 — 紧凑弹幕行间距测试

- 弹幕设置新增「弹幕行间距 → 紧凑」，可配合「弹幕密度 → 密集」使用，让上下行更靠近。
- 点播、直播和设置预览共用，修改后自动保存，播放中调整立即生效。
- 默认仍为标准行间距，保留现有字号、描边和弹幕数量上限。
- 包含 legacyfix.5 的播放控制栏改进与诊断功能。

独立测试包，不进入 Homebrew 或正式自动更新。

## 复测

覆盖安装 Assets 中带 legacyfix.6 的 IPK，设置 → 关于确认版本，无需退出账号。

播放中进入设置 → 弹幕设置，将密度选为「密集」，行间距选为「紧凑」，对比标准行距。请留意大字号、粗描边是否重叠，切换视频后设置是否保留；直播也可以使用同一设置。

仍有问题请附视频 BV、字号／描边／密度设置及截图。需要回退时可覆盖安装 legacyfix.5。
