# 账号修复（2.5.0 候选）

设置 → 账号修复提供分级操作；打开面板不会自动修复或播放视频。检查有效登录与服务支持情况、清理临时签名缓存、主动重建设备标识、重新扫码登录是独立操作。不保证解决平台风控或任何播放故障。

## 已核对的 issue 方法

- [#50](https://github.com/asdf17128/bili-webos/issues/50)：Node 20 / Chrome 132，部分 API 正常，playurl 在媒体请求前失败；未提供成功修复记录。
- [#51 的报告者回执](https://github.com/asdf17128/bili-webos/issues/51#issuecomment-6293005593)：LG C2 / Node 16，保留 SESSDATA、替换 buvid3 / buvid4 / b_nut 后恢复；普通退出再登录未解决。报告中旧接口 -351，WBI 接口 code=0 但只有 v_voucher、无可播放流。这是单个环境的用户证据，不是已独立证明的普遍根因。
- [#52](https://github.com/asdf17128/bili-webos/issues/52)、[相关评论](https://github.com/asdf17128/bili-webos/issues/52#issuecomment-6331018880)：Node 8 / Chrome 68 类似故障，没有成功修复回执。

没有实现评论中未经验证的 ExClimbWuzhi 激活、位置伪造或手工粘贴凭据。保留 2.4.1 的有限自动风控恢复，最多重试一次，与手动重建互斥。已有退出逻辑保留设备 cookie；服务启动时已有 buvid3 会跳过初始化，前端直播 ensureBuvid 原先另有更新路径，不能概括成所有路径从不更新。

## 操作与影响

1. **检查账号**：查询 nav 与本机服务状态，只显示有效/失效/未确认、原始整数错误码和服务是否支持。登录有效不代表播放已恢复；不请求视频。
2. **刷新临时缓存**：清空内存 WBI 密钥缓存再检查，保留登录、设备 cookie、偏好与历史。清理前的在途响应不能回填旧缓存。
3. **重建设备标识**：检查服务支持后才可选择；独立确认页默认选中“取消”，说明替换影响。确认只向固定官方 `/x/frontend/finger/spi` 发一次匿名请求，使用独立且验证证书的 TLS 连接；不携带已有登录 cookie，不进行激活或重试。与自动恢复共享 5 分钟冷却，失败尝试也写入磁盘并跨服务重启保留。
4. **重新扫码登录**：另有确认页并默认取消，打开既有登录二维码，不先退出旧账号。用户在手机确认后才按既有登录流程更新账号；取消/生成失败不主动清除旧登录。这不保证解决设备标识问题。

新设备响应必须同时提供合法且已变化的 b_3、b_4，接受接口实际返回的 Base64 字符。b_nut 是可选字段：有返回时严格校验可信 Set-Cookie，没有返回时移除旧值，不本地编造。2026-10-24 使用生产模块、匿名真实接口和隔离临时文件验证成功；旧实现会拒绝该响应，已保留失败正对照。此验证不等于电视旧 TLS 或报告者账号的现场修复有效。

服务先在同目录以 0600 独占创建临时文件，完整写入、fsync、关闭，原子 rename 后再更新内存。提交点之前任一步失败均保留旧文件与旧内存。成功后没有自动还原旧标识的功能，确认页已说明。仅更新设备字段，保留其余 cookie、设置与历史；不会先清空 cookie 文件。

修复期间阻止普通请求与 cookie 写入；已有请求、启动初始化和迟到前端写受会话代次及 `onlyIfDeviceMissing` 条件保护。已有退出操作可以中断修复，旧响应不能把退出前的账号恢复回来。

## 失败、隐私与边界

明确服务业务失败显示旧值保留；连接中断、客户端超时或响应格式异常显示“结果未知”，不声称服务一定没改。客户端保持并发锁直到在途操作结束；同账号未知结果会清理旧本地设备缓存，下次使用从服务重新读取，不自动重试。账号切换后丢弃旧操作结果，不清理新账号缓存。

公开结果由固定字段重新构造：操作/状态枚举、整数错误码、登录状态、服务支持/忙碌/冷却布尔与秒数、`playback: unchecked`。不导出原始响应、错误文本、账号、cookie/token、IP、设备标识或观看内容。没有新增远程日志或自动遥测，也没有修改已有 DAU 任务。普通检查依然需要已有账号鉴权；不能把“不展示敏感字段”误称为所有请求都不带登录 cookie。

## 验证与发布边界

确定性服务/客户端/浏览器测试全部使用隔离 fixture。实际 Node 0.12.2 与 8.17.0 执行新设备更新模块的内存测试，不启动真实服务或连接真实账号；不等于 webOS/Luna、真实上游或电视验收。

详见 [开发复跑说明](DEVELOPMENT.md)、[功能清单](FEATURES.md) 和 [测试记录](TESTCASES.md)。当前为 2.5.0 合并候选，尚未发布；本地验证已完成，用户随后允许真机验证，最终包长测进行中，发布门禁保留。
