## 发现并修复

- 搜索页写死四列，现跟随每行视频设置。
- 静止指针被滚动内容触发 hover，抢走方向键焦点；现由真实鼠标移动切回指针模式。
- 我的页原生滚动被误清零，最大卡片可能落到屏幕外；原生与 transform 网格分别处理。
- 已取消的播放器继续重试；网络故障反复走整条画质阶梯。
- API 响应体中断不回调、Luna 无截止时间，可能一直加载。

复现与修复证据：[浏览器](ux-evidence/2026-09-06-release-2.0.0/browser.json)、[加载回归](ux-evidence/2026-09-06-release-2.0.0/loading.json)、[搜索列数对照](ux-evidence/2026-09-06-release-2.0.0/columns-before.json)、[焦点对照](ux-evidence/2026-09-06-release-2.0.0/pointer-before.json)、[我的页对照](ux-evidence/2026-09-06-release-2.0.0/library-before.json)。

## 测试边界

这是全套现有自动化门禁、真实接口回归和一台 LG C4 的真机验证，不代表所有 LG 型号/网络/视频编码组合均已实机覆盖。旧设备已验证服务 Node 8 与构建兼容，未另有 webOS 5/6 实机。字幕/弹幕四档字号测试使用真实 React DOM 与控制数据；真实解码由点播和直播套件单独验证。DLNA 协议与状态测试通过，本轮没有手机端完整投屏实测。上游 CDN/API 仍可能间歇超时。
