# 2.6.0 legacyfix.3 — 控制栏与快进体验测试

- 进一步改善旧电视控制栏左右切换时的响应，保留现有按钮、功能与高亮动画。
- 长按快进时只移动预览位置，松开后再加载最终位置的预览图，并在停下约一秒后跳转；按确认可立即跳转，按返回可取消。
- 快进保持清晰的 10 秒步进，减少长按卡顿后突然跳到很远位置的问题。
- 进度条选中时明显高亮，显示放大的圆形游标、目标时间和前进／后退秒数；预览信息与视频标题分开，适配 720p 大字号。
- 保留此前旧电视账号播放恢复修复。

这是独立测试包，不进入 Homebrew 或正式版自动更新。旧电视实际改善幅度仍需原设备确认，起播较慢的问题继续单独跟进。

## 安装与复测

下载 Assets 中带 `legacyfix.3` 的 IPK，用 webOS Dev Manager 覆盖安装，无需卸载、退出账号或重建设备标识。设置 → 关于确认 **2.6.0 legacyfix.3**。

请使用之前卡顿的同一视频、相同画质和弹幕设置，对比：

1. 控制栏短按、持续长按 3–5 秒是否更跟手。
2. 长按快进时是否仍会明显卡住、突然跳很远；松开后是否只跳转一次。
3. 进度条选中状态、目标时间和预览图是否清楚；按返回能否取消跳转。

请反馈 BV、画质和实际感受；如果仍卡，可补充暂停视频后操作是否改善。发生播放失败时，请在换片或重启前生成新版网络诊断。无需提供账号凭据。

如需回退，可覆盖安装 legacyfix.2。
