# BiliTV v2.3.0

这次更新加入 UP 主关注入口，并改善网络中断后的播放恢复。

- **关注 UP 主**：播放控制栏、视频卡片长按菜单可关注或取消关注，成功后同步首页标记；失败会给出提示，不错误切换状态。
- **中断后继续播放**：网络错误或持续卡顿后，保留当前分 P 和进度；最多自动重试两轮，也可按 OK 手动重试，返回退出即取消。
- **请求不会无限等待**：DNS 查询、连接池排队和响应头都有总超时；取消播放或测速时及时释放尚未建立的代理请求。读取请求在收到响应前断开时，换新连接重试一次；关注等写入不会重发。
- **C9 起播优化**：为 DASH 清单明确指定格式，减少不必要的格式探测；保留分阶段起播及 CDN 诊断。社区 C9 测试包反馈的六次起播均为零网络重试，实际耗时仍取决于片源、设备和网络。
- **更准确的风控提示**：引导在官方客户端对照同一账号，避免仅凭错误码误判封号。
- **旧电视兼容与安全维护**：更新开发工具 WebSocket 依赖，为 Node 0.12 兼容路径增加接收上限，保留 Node 8 兼容性。

适用于从 v2.2.3 或 c9-test / recovery-test 测试包直接升级，保留登录与设置。正式包不再显示测试标记。

验证详情和未覆盖的硬件范围见仓库 [测试记录](https://github.com/asdf17128/bili-webos/blob/main/docs/TESTCASES.md)。应用恢复改进不能代替修复网络中的 DNS 服务器或路由器故障。
