# 粉丝数随控制栏一起淡出

根因：showControls=false 立即禁用 useAuthorFollowers，返回 null 并清空状态，但父控制栏还有 300ms opacity 动画，导致数字提前卸载。

修复：enabled 只控制请求及未完成响应交付；已取得的同视频／同 UP 数字在隐藏时保留，再打开不重置为空。身份 guard 继续阻止切换视频／UP 时出现旧数字。

正对照：旧代码在真实淡出帧采样下 0/1，数字节点提前消失。新版相关浏览器用例 6/6，包括逐帧节点连续性、重新展开、自动隐藏、零粉丝、未知和失败。真实 Hook／Store 隔离检查 9/9，包括换 UP、换视频、迟到响应、不发多余请求和删除 guard 的突变对照。生产构建通过。仅本地合成数据，未访问电视，未发布。
