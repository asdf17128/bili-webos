# v2.2.0 — 播放更顺，订阅更方便

- **点播 CDN 自动择优**：根据实际媒体下载速度选择线路，加入华为云 HWO1 候选；保留手动选线、原生签名和失败回退。暂停或缓冲充足时测速，后续分片生效，无需重载视频。
- **直播起播优化**：保持所选画质，优先起播更快的 fMP4 HLS，不支持时回退 TS；取流与画质信息共用一次请求，加载状态持续到真正开始播放，失败后可遥控重试。
- **卡顿恢复与诊断**：缓冲耗尽时显示加载并有限恢复；网络诊断按所选线路测速，记录实际播放节点、卡顿和自动选路状态。
- **收藏新增「订阅」**：支持已订阅的他人收藏夹和 UP 主合集、分页与跨页播放。
- **遥控焦点修复**：修复快速重试后方向键失效、从搜索切换到设置跳过第一行；返回侧栏保持位置，确认侧栏仍主动刷新。
- **分区与评论修复**：修复排行榜请求上下文导致的 -352；修复评论栏错误文本、空态混显及控制条遮挡。
- **兼容与音视频**：整合社区 webOS 4.x 布局和 Node 0.12.2 兼容方案；改进杜比初始化段识别及 E-AC-3 / FLAC / AAC 音轨选择和回退。补充独立 MIT LICENSE。

## 更新

从本发布页下载 `com.biliwebos.app_2.2.0_all.ipk` 安装，或等待 Homebrew Channel 目录同步后更新。应用检查更新与 Homebrew manifest 已随安装包一起发布。

CDN 建议先选「自动择优」。首次无缓存仍立即使用原线路；持续缓冲不足时可以暂停一会，让后台完成候选测速，再继续播放。不会将所有 Akamai 地址盲目替换为镜像域名。

## 验证与已知范围

- 本批功能此前在 LG C4 完成点播、直播、实时弹幕、账号读取及遥控回归（53 通过、0 失败、3 跳过）；v2.2.0 的最新真机复验为 15 通过、13 失败、3 跳过，出现应用退出及导航状态异常，尚未确定原因，不能称最终真机全量通过。已停止设备操作，保留失败记录。当前版本电脑真实网络模拟 55 通过、0 失败、2 项因本机登录失效跳过；浏览器交互 61/61、点播失败路径 17/17、直播 9/9、CDN 7/7 与真实 Node 0.12.2/8 自动层通过。详细结果见 [测试记录](https://github.com/asdf17128/bili-webos/blob/v2.2.0/docs/TESTCASES.md)。
- 香港、日本匿名服务器出口各通过 11 项 API 和真实媒体传输检查，并选中不同的较快节点；这不代替海外家庭电视实播或长期吞吐保证。
- webOS 4.x 兼容方案来自 #34 社区贡献，本项目已验证旧运行时和布局降级；仍欢迎旧电视用户反馈实际播放、直播弹幕和 DLNA。
- 杜比音轨选择不代表 Atmos 一定输出；实际 DV/HDR/Atmos 取决于片源、电视和音响链路。未包含 PR #17 中特定 4K120 片源帧变换；超过 60fps 或帧率未知的片源保持原有基础层信令，避免直接开启杜比信令的已知黑屏风险。相关设备仍需现场验证。
- #41 报告的“关闭自动连播对收藏夹等不生效”及循环播放请求未包含在本次修复中，继续跟踪。

感谢 #34 的 @adin1234567 提供旧电视兼容方案，感谢 PR #17 的 @SSSS-VIII 贡献及各位 issue 报告者提供诊断和实测。

## English

- Automatic DASH CDN selection using small real-media probes, with an HWO1 option, manual override and native signed URL preservation.
- Faster live startup at the saved quality, fMP4 HLS preference with TS fallback, accurate loading state and bounded retry.
- Recovery when buffers run out, and diagnostics that report the selected route and actual playback node.
- A **Subscriptions** tab for followed folders and creator collections.
- Fixes for retry/cross-page remote focus, category ranking requests and comment rail rendering.
- Community-based webOS 4.x / Node 0.12.2 compatibility work, improved Dolby initialization/audio selection and an explicit MIT license file.

Earlier feature validation passed on LG C4. The latest v2.2.0 TV rerun recorded 15 passes, 13 failures and 3 skips with app exits/navigation errors; the cause is unresolved and device testing has stopped. It is not a clean final hardware acceptance. Current browser/runtime regressions and earlier anonymous network checks from Hong Kong and Japan are recorded separately. Old-TV playback, affected overseas home connections and actual Dolby Vision/Atmos output still need device-specific confirmation. Issue #41 (autoplay-off behavior for playlists and a repeat-mode request) remains open and is not fixed in this release.
