# Android 工程启发的弹幕体验增强（未发布）

参考前一轮对 `cat3399/blbl` 固定提交的源码研究，详见 [功能文档](../../FEATURES.md)。独立实现适合 webOS DOM/CSS 渲染的功能，没有移植 Android 线程或位图缓存。

## 本轮实现

- 点播控制栏增加「弹幕设置」，保留原来一键开关弹幕的按钮。确认后保存并应用于当前播放器；取消未确认的选项、返回、关闭后的遥控焦点均保留原有交互语义。打开面板不改变媒体播放状态，关闭不重载视频。
- 稀疏、标准、密集同时影响轨道间距与 12/24/48 条节点上限。最小间距预留最大支持字号的行高、描边和安全距离，兼顾不同源字号。点播、直播、设置预览共用。
- 点播拥塞项可以在原时间点后最多 1 秒内重试。最多扫描 128 条；不额外保留无界队列，过期、跳转、关闭时不积压。
- 按文字和字体参数缓存测量宽度，最多 512 项，超过时淘汰旧项。点播、直播、预览共用。
- 修复打开弹幕设置时静止指针触发 hover、抢走遥控初始选中项的问题。
