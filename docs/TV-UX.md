# 电视端 UX 优化 · 2026-09-06

这份记录对应第一轮交互修复，保留当时的蓝色视觉语言。随后用户要求整体重设计，当前视觉方案与新截图见 [内容画廊重设计](TV-REDESIGN.md)。原生系统搜索键盘、零 React 渲染焦点和 transform 网格滚动继续保留。

## 侧栏的明确语义

用户在本轮确认：**侧栏确认刷新是 feature；移到侧栏导致列表回到开头是 bug。**

| 操作 | 行为 |
| --- | --- |
| 内容区按 Back / 首列按左 | 只回侧栏，列表保持原位置 |
| 侧栏按右 | 进入该栏目，恢复原卡片及滚动位置 |
| 当前栏目侧栏按 OK | 主动重新获取列表，回到开头 |
| 快速上下经过侧栏 | 先移动焦点；停稳 180ms 后再预览 |
| Magic Remote 悬停 | 只高亮，不滚动列表，不打开登录 |

栏目数据只保留最近 4 栏、每栏最多 200 条元数据、有效期 5 分钟，不保留图片对象。刷新版本按栏目记录，因此刷新热门不会清空推荐的浏览位置。

## 改动覆盖

- 首页增加栏目标题、网格骨架和遥控提示；明确区分加载、空列表、错误和到达末尾。
- 加载错误提供可聚焦的重试；预取与前台翻页共享请求，过期响应不写回已离开的栏目。
- 网格按真实视口高度夹住滚动范围；收藏夹选择器和页眉不会再挤掉最后一行。悬停不走直接滚动；滚轮可以滚到已被指针高亮的行。
- 卡片保留显眼的焦点边框，提高元信息对比度；封面失败显示占位文案，直播展示状态标记。
- 搜索保留原生退格、光标移动和输入法组合；仅最新请求可更新结果，失败不再伪装为无搜索结果。
- 登录弹层隔离方向键、确认和滚轮，失败可重试，返回可取消；关闭后不继续轮询或发起过期登录回调。
- 收藏夹空响应结束加载；切换时的旧请求不能覆盖当前收藏夹；从第一排上移回到当前收藏夹。
- 播放器模块加载期间提供标题、反馈和退出入口，隔离隐藏页面操作；模块加载异常有可退出的错误页面。
- 中英西三语同步；侧栏随语言及字号调整，标签换行；减少动态效果时关闭浏览过渡。

## 验证及边界

自动浏览器用 Playwright 的真实键盘/鼠标输入管线，所有 API 都是隔离夹具，不访问真实账号。旧版从本轮开始时的 HEAD 单独导出运行，不覆盖工作区；失败路径用 `route.abort()`，乱序请求通过延迟响应构造。

```sh
# 本地规范、逻辑、真实 Node 8、构建与遥控器 UX 回归
bash tools/verify.sh --no-tv --ux

# 已启动 Vite 时单独执行
npm run test:ux

# 安装开发版到电视后验证，包含普通播放及观看历史
npm run test:ux:tv
```

本轮浏览器测试覆盖 24 个场景。旧版对照复现初始无焦点、悬停滚动、侧栏右键回首卡、键盘退格失效、旧搜索覆盖新搜索、登录穿透、空收藏夹一直加载等问题；**旧版确认刷新的测试本来就通过**，此次予以保留。三语深滚动几何在旧版和新版均通过，用作回归保护，不计为新增修复。

真机开发版已验证：

- 回侧栏前后 transform 都是 `translateY(-999px)`；右键返回 `content-3-1`。
- OK 刷新后是 `content-0-0`、`translateY(0px)`。
- 深处 `content-10-0` 完整处于内容视口；真实视频起播达到 `readyState=4`。
- 退出播放恢复到 `content-10-0` 和原滚动偏移。

真机首轮还抓到一次刷新后焦点消失：在旧卡片卸载前，延时焦点请求已被旧卡片消费。改为按栏目刷新版本重建列表、在新提交后请求焦点，真机复验通过。这个结果不能由桌面快机器上的成功推断。

截图和机器可读结果默认输出到 `/tmp/bili-tv-ux/`。测试报告及关键截图归档于 `docs/ux-evidence/2026-09-06/`。这轮验证了交互行为和布局，没有进行帧率或首帧耗时 A/B 测量，不宣称性能提升百分比；也未发布公开版本。

## 设计依据

电视导航需要清楚可辨的焦点，以及方向输入和指针输入之间一致的选择行为。参考 [LG Magic Remote 指南](https://webostv.developer.lge.com/develop/guides/magic-remote) 与 [Android TV 导航指南](https://developer.android.com/training/tv/get-started/navigation)。返回键沿应用层级返回，并在入口交给系统，参考 [LG Back Button 指南](https://webostv.developer.lge.com/develop/guides/back-button)。具体刷新与侧栏恢复规则以上述用户确认为准。
