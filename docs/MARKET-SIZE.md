# 中国区规模估计:方法与结论

**问题**:装了 Homebrew Channel 的中国 LG 电视有多少台?我们(BiliTV)覆盖了其中多大比例?

**结论先行(2026-08-02)**:中国区活跃 Homebrew 设备**约 400–1,500 台**,我们覆盖 **30%–100%**,
最可能落在 **50%–90%**。这个区间宽,但每一步的依据都写在下面,可以被逐条质疑和更新。

---

## 一、为什么这题难

目标人群是典型的**隐藏人口(hidden population)**:没有注册表、没有官方统计、成员不自我披露。
社会学/流行病学里估计这类人群有成熟方法(捕获-再捕获、多重系统估计、网络规模法、基准-乘数法),
但它们几乎都需要**新采集数据**(问卷、链式招募),而我们:

- 不采集用户数据(隐私底线,也不该为了一个统计数字破例)
- 发帖做调查的样本代表性不成立(见 §五「被否决的方案」)

所以这里只用**两类不打扰任何人的数据**:公开的行业数字,和 GitHub 上可精确计数的下载量。

## 二、两条独立路径

### 路径 A:自上而下(市场漏斗)

| 环节 | 数值 | 性质 |
|---|---|---|
| 全球 webOS 设备 | 2.4 亿(2025-09,LG 官方) | 硬数据 |
| 全球 Homebrew 活跃装机 | **32,612**(hbchannel 最新版 ipk 下载) | **硬数据** |
| **全球越狱渗透率** | **0.014%** | 前两项相除 |
| 中国电视年出货 | 3,596 万台(2024) | 硬数据 |
| 外资品牌(三星+索尼+LG)中国份额 | 不足 3%(2026Q1) | 硬数据 |
| LG 中国年出货 | 10–30 万台 | **推算**(取合计的约 1/3) |
| LG 中国保有量(7 年寿命) | 70–200 万台 | **推算** |
| **× 全球渗透率** | **100–280 台** | |

### 路径 B:自下而上(从我们自己反推)

我们的活跃装机可以**精确数出来**:Homebrew 自动更新是每台设备每版下载一次,所以
"单个版本的 ipk 下载数 ≈ 当时的活跃装机数"。

| 版本 | ipk 下载 |
|---|---|
| v1.3.0 | 391 |
| v1.4.0 | 477 |
| v1.5.0 | 432 |

→ **活跃装机 ≈ 433 台**(近版均值),占全球 Homebrew 活跃装机的 **1.33%**。

设 p = "中国 Homebrew 用户里装了 BiliTV 的比例",则中国盘子 = 433 / p:

| p | 盘子 |
|---|---|
| 90% | 480 台 |
| 60% | 720 台 |
| 30% | 1,440 台 |

p 应当偏高:BiliTV 是官方目录 45 个应用里**唯一的中国向应用**,而中文用户装 Homebrew 的
首要动机就是看国产内容。

## 三、两条路径对不上 —— 这才是关键发现

路径 A 给出 100–280 台,但路径 B **实测就有 433 台**。下界超过上界,说明**模型错了**,而不是误差。

最可能的解释(按可信度排序):

1. **中国的越狱渗透率显著高于全球平均。** LG 中国版 webOS 没有 B站/爱奇艺/腾讯视频,
   不越狱几乎看不了国产内容;欧美用户官方就有 Netflix/YouTube,动机弱得多。
   若中国渗透率是全球的 3–5 倍(0.05%–0.07%),盘子 = 400–1,400 台,**与路径 B 吻合**。
2. **LG 中国保有量被低估**:水货、海淘、港版机器不进中国出货统计,而这在 LG OLED 上很常见。
3. **全球分子被低估**:不升级到最新版的老用户没被 hbchannel 最新版下载数计入。

**这个矛盾本身是有价值的产出**:两条独立路径共同指向"中国用户的越狱动机远高于全球平均"。

## 四、每月自动追踪(唯一保留的自动化)

只记录两个**纯硬数据**,不含任何假设:

```
全球 Homebrew 活跃装机 = hbchannel 最新版 ipk 下载数
我们的活跃装机       = 我们近 3 个版本 ipk 下载数的均值
比值                 = 我们 / 全球        （2026-08-02 基线:1.33%）
```

比值的**走势**比绝对值有意义得多:同一把尺子量涨跌是准的。
配合日活(tools/dau-daily.sh)一起看:装机是存量,日活是活跃度。

## 五、被否决的方案(以及为什么)

| 方案 | 否决理由 |
|---|---|
| **论坛发问卷**(恩山/V2EX)测"装了 BiliTV 的比例" | **代表性不成立** —— 恩山用户代表不了中国 Homebrew 用户;V2EX 还被我们自己的宣传帖污染过 |
| **捕获-再捕获**(B站 教程评论者) | 违反样本独立性(同平台同算法)与捕获概率同质性;实测两视频重叠仅 1 人,估计值极不稳 |
| **多重系统估计**(跨平台名单) | 跨平台匹配用户身份不可靠,且涉及个人数据 |
| **收藏率/播放量推转化** | "收藏=潜在装机上界"是拍脑袋 —— 真正会折腾的人恰恰不收藏 |
| **网络规模法(NSUM)** | 需要向一般人群发问卷,我们没有这个渠道 |
| **B站 教程播放量 × 转化率** | 转化率无法实测(没有任何视频在讲我们的 app,做不了自然实验);且教程观众混入大量三星/索尼/小米用户 |

## 六、什么情况下该重估

- 出现**第二个中国向 webOS 应用** → 可以做真正的交叉验证(两个应用的装机重叠/比例)
- webosbrew 官方公布按国家的下载分布 → 直接拿到分母,本文档作废
- 我们的装机量出现数量级变化 → 路径 B 的锚点变了,结论要重算
