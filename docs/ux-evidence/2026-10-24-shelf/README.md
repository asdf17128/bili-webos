# 控制栏展开修复

播放器全局滚轮处理主动让出输入，但控制栏没有接管，造成滚轮无法拉起推荐区。补上控制栏内向下展开、列表到顶向上收起；展开后仍由列表原生滚动。

展开/收起使用 280ms transform 动画，避免逐帧重排所有卡片。快速返回从当前视觉位置反向，减少动态效果偏好关闭动画。标题、字幕与进度条仍按最终布局计算。
