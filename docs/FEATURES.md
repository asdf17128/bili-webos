# 当前功能清单

本清单对应 **2.5.2**（下方另列未发布功能），包括内容浏览、点播与直播、会员影音、推荐反馈、账号修复和诊断等功能。

| 范围 | 已实现能力 | 状态／边界 |
|---|---|---|
| 内容浏览 | 推荐、热门、直播、关注、收藏与订阅收藏夹／合集，游戏、动画、音乐、知识、娱乐、鬼畜分区 | 已发布基础能力 |
| 搜索与继续观看 | 热搜、联想、搜索历史、观看历史、继续观看、稍后再看 | 独立搜索排序与会员专属频道尚未新增 |
| 遥控与布局 | 方向键、播放／暂停媒体键、长按菜单、指针、滚轮；返回关闭控制栏后忽略指针抖动；侧栏返回保留卡片和滚动位置；当前栏目 OK 主动刷新 | 每行 2／3／4 列；界面、字幕和弹幕独立字号 |
| 账号与互动 | 扫码登录、会员／年度会员标识，关注／取消关注 UP，点赞、投币、收藏、长按三连 | 真实账号写入须与模拟验证区分 |
| 点播 | 续播、选集／分 P／合集、章节、快进缩略图、确认／取消跳转、倍速、字幕、弹幕、评论与回复 | 倍速电视路径与浏览器不同，需真机验证 |
| 播完行为 | 自动连播、播完停止、单集循环；可选看完移出稍后再看 | 偏好持久化，播放队列与分 P 适用 |
| 会员影音 | 自动最高可用／手动画质；4K、兼容设备上的 8K、HDR／Dolby；独立选择 E-AC-3 → FLAC → AAC | 受片源、账号、地区和硬件限制；特定 120→60fps Dolby 路径不是通用转换；不等同于 Atmos 音响验收 |
| 直播 | 清晰度、实时弹幕、聊天栏、格式回退、CDN 轮换、卡顿后有限恢复、退出清理订阅 | 安静房间不能证明弹幕连续性；原生 HLS 统计有限 |
| 网络与恢复 | 自动 CDN 择优及手动线路、原始备用签名地址、有限重试、DNS／连接池总超时、播放风控设备恢复及受控激活（持久化冷却、最多一次取流重试） | 不保证解除账号、地区或运营商限制 |
| 技术信息 | 点播／直播 Nerd 开关：分辨率、编码、帧率、CDN、缓冲、丢帧和可观测媒体下载统计 | 不可观测指标显示未知，不虚构网卡流量 |

| **UP 粉丝数** | 播放控制栏显示公开粉丝数；缓存、失败不伪造数值，切换作者时不会残留上一位数据 | **2.5.1 新增** |
| **透明控制栏** | 渐变透明背景、标题／作者／控件重新排布，兼顾评论栏、小屏幕和大字号；字幕避让，向上延伸显示两排正常视频卡片、连续展开收起与逐排平滑浏览；加重白字配细黑边，粉丝数同步淡出 | **2.5.1 新增**；不是“透明度设置滑块” |
| **不感兴趣** | 推荐卡片长按区分当前视频／UP；确认后官方反馈或明确本机隐藏；原 reason 撤销、独立恢复本机显示；UP 按账号隔离 | **2.5.1 新增**；UP 反馈不是账号拉黑，恢复本机显示不等于撤销远端算法反馈 |
| **账号修复** | 检查登录、清理临时 WBI 缓存、确认后重建设备标识、重新扫码登录；统一入口 | **2.5.1 新增**；与自动恢复互斥，共享持久化 5 分钟冷却，不保证修复平台风控 |
| **诊断报告** | 本机预览，用户主动生成反馈二维码；阶段耗时、HTTP／API 码、是否有媒体流、失败与恢复前后结果 | **2.5.1 增强**；白名单输出，不导出视频 ID／账号标识／IP／凭据／原始错误；服务重启清空故障记录 |

详细边界：[会员与画质](MEMBER-EXPERIENCE.md)、[Dolby](DOLBY_VISION.md)、[推荐反馈](DISLIKE.md)、[账号修复](ACCOUNT-REPAIR.md)、[测试登记](TESTCASES.md)。

## 未发布：点播控制层级

点播主控制条固定为三组，组间留白，打开时焦点落在播放／暂停：

| 位置 | 按钮顺序 |
|---|---|
| 左侧互动 | 点赞、投币、收藏、稍后再看 |
| 中间播放 | 上一个、播放／暂停、下一个 |
| 右侧入口 | 评论、设置 |

点赞短按与长按三连、独立投币／收藏及互动计数保留在主层。未登录时互动按钮不可用；方向键跳过不可用按钮。时间与当前章节归入进度区，评论数量在打开评论前显示。

主栏以大图标为主，圆形按钮在聚焦时显示白底、蓝色外圈和深色分隔边，并轻微放大；功能名称与完整计数显示在固定的焦点说明行。常驻互动计数保留，窄屏过长数字可以省略；长按三连的进度环跟随圆形图标，成功反馈不移动数字。按钮名称仍提供给无障碍读取。[大图标本地验证](ux-evidence/2026-11-07-large-control-icons/README.md)。

「播放设置」使用纵向菜单，集中画质、倍速、字幕（有字幕轨时）、弹幕开关、弹幕设置及关注 UP 主，并显示当前选择或状态；上下键选择、OK 执行。画质、倍速、字幕子面板选择或返回后，焦点恢复到设置中的原条目；关闭弹幕设置也回到对应条目。再次返回回到主控制条的设置按钮。播放结束或致命播放错误会关闭面板并取消未完成的长按，避免迟到账号操作。

上一个／下一个按当前播放列表、分 P、合集或番剧顺序切换，跳过失效项，手动切换一律从头播放。视频顺序不首尾环绕；普通视频的上一个不可用，下一个选择相关推荐。没有可切换内容时按钮不可用，遥控方向键会跳过。

本轮保留两排推荐卡片和 transform 展开结构，直播控制布局沿用原设计。[实现与验证记录](ux-evidence/2026-11-07-three-group-controls/README.md)列明本地测试范围，没有电视操作或发布。

## 未发布：弹幕自定义（#66）

[逐项需求对照与本地全量验证](ux-evidence/2026-11-06-issue66-completion/README.md)。

设置 → 弹幕设置：字号 4 档、不透明度 25/50/75/100%、粗细 3 档、描边 3 档、顶部 1/4／1/2／3/4／全屏区域、12/24/48 条密度上限、慢／标准／快三档速度，以及滚动、顶部固定、底部固定、彩色弹幕开关。预览即时变化，选项确认后自动保存；全局设置在下次播放使用。点播从控制栏「设置 → 弹幕设置」进入，直播仍从控制栏进入；调整当前播放立即生效，不重载媒体或改变播放进度。返回可取消未确认的选项，关闭后焦点回到原入口。

点播支持普通滚动（模式 1/2/3）、反向滚动（6）、顶部固定（5）、底部固定（4），高级定位／脚本弹幕不执行。彩色开关关闭时过滤非白色弹幕。固定底部指所选显示区域的底部。直播当前接收纯文本滚动消息，应用外观、速度、区域、密度与滚动开关，不凭空添加颜色或固定模式。直播面板和预览仅展示当前适用选项，不显示人物遮罩加载状态，保留点播的类型与遮罩偏好。外观设置与点播共用。

密度是同时显示数量上限，不保证每个时间点都有足够数据；点播按六分钟分段获取弹幕，优先当前段并预取下一段，最多缓存三段；失败时回退一次 XML，并按段冷却重试。跳转后隔离过期响应，切换分段不清空正在飞行的弹幕。不包含历史弹幕查询。每次最多扫描 128 条、允许拥塞项在原时间点后 1 秒内重试，过期即丢弃，不建立无界队列。密度同时调整轨道间距和同时显示上限；轨道预留最大支持字号的行高与描边，采用恒定像素速度避免追撞。文字测量缓存最多 512 项，点播、直播和预览共用。暂停、跳转、关闭和设置变化会正确冻结或清理动画。

## 未发布实验：智能防挡人物

弹幕设置 →「智能防挡人物（实验）」，默认关闭。点播通过当前 CID 对应的播放器元数据获取官方 `.webmask`；根据播放时间，给弹幕层应用人物轮廓遮罩，不修改视频画面、字幕或控制栏，也不在电视上运行人像识别模型。

只支持提供有效遮罩的点播视频。无数据、设备不支持或加载失败时显示对应状态并保留普通弹幕；直播和缺少元数据的番剧不启用。失败后不会循环重试，可关闭后再打开显式重试。

按 Range 读取索引、当前段与下一段，最多缓存两段；单段压缩上限 512 KiB、解压上限 2 MiB、最多 600 帧。优先跟随视频帧回调，旧浏览器使用动画帧；预选有界时间窗口内的轮廓，跨分段衔接。未来帧为空时，只短暂使用当前仍有效的轮廓，避免切镜前提前失去保护；跳转立即清旧遮罩，准备变慢时也不保留超过 80 ms 的旧展示状态。

使用稳定的内联 SVG 遮罩引用，同步更新已校验的矢量轮廓，不读取视频像素，也不进行逐帧 PNG 编解码。边缘留白仅用于可确认的单个闭合填充几何，其它形状保留源轮廓；最多缓存 8 帧已准备几何与 2 个源分段。按视频实际比例定位，保留黑边区域的普通弹幕；退出、关闭和切源释放缓存、SVG 资源及回调。

源数据可能遗漏人物或有切镜时差，边缘留白无法补出缺失的轮廓；源帧没有人物洞时显示无保护状态，保留普通弹幕，不借用上一镜头的形状。该功能仍为默认关闭的实验功能，不保证所有人物、发丝和快速运动边缘都被保护。

[最新连续播放与电视排查记录](ux-evidence/2026-11-07-mask-flicker/README.md)：本地连续轮廓、真实媒体及像素检查通过；修复原生视频帧回调静默后，最终包 30 秒电视自动化复验的 446 个样本中未出现遮罩丢失、开关切换或过期轮廓。电视截图只能捕获 App 叠层，实体避让效果与流畅观感尚未经用户确认；不等于长期或全片源验收，未发布。此前的[本地优化与截图](ux-evidence/2026-11-06-person-mask-optimization/README.md)保留为历史记录。

## #66 参考工程研究（2026-11-05）

研究对象：`cat3399/blbl`，固定源码提交 `cd09bd903e6d0c22f5986580c2105796d8df6471`。这是源码审阅及接口对照，没有运行 Android 实机，不将其实现等同于 webOS 的性能结论。此前本地提交 `b78e61e` 是设置/渲染原型，尚未推送或发布；不能据其已有设置项宣称已解决弹幕数据覆盖问题。

| 观察到的实现 | 对 bili-webos 的启发 | 当前原型差距 |
|---|---|---|
| `VideoApi.dmSeg` 使用 protobuf 分段接口；播放器默认每段 6 分钟，按进度请求当前段并预取后两段，最多缓存 20 段 | 优先补分段数据加载、拖动后的目标段请求、去重、有界缓存和过期结果隔离；电视端缓存预算应独立验证 | 研究时仅读取 XML 弹幕池；本轮已补独立分段加载实现，等待完整长测验收 |
| `DanmakuLaneDensity` 改变轨道高度因子；引擎以字形高度和描边确定轨道最小高度 | 密度需要同时考虑轨道间距和全局节点预算，不能只把 24 改成 48 | 已实现按密度调整间距，预留字号/描边安全高度 |
| 播放中有弹幕设置，配置更新会重排并使相关文字缓存失效 | 在当前视频上即时看到修改；样式改变应清理旧轨道/缓存并保留播放进度 | 点播与直播均已有控制栏即时设置，直播只展示支持的选项 |
| 动作线程、位图缓存线程和主线程绘制快照分离；缓存、每轮生成数量和短延迟队列均有上限 | 借鉴分工和预算机制；webOS 继续优先验证 CSS 合成动画，缓存文字测量结果并约束每轮工作 | 不应直接照搬 Android Canvas/HandlerThread 或 50MB 位图池 |
| 拥塞弹幕有短暂、有限的重试；超过时限丢弃 | 降低瞬间拥塞导致的无条件丢弹幕，仍避免长时间积压后扎堆出现 | 已增加点播最多 1 秒的有界窗口重试；直播仍直接丢弃拥塞消息 |
| 本地类型开关之外还有关键词/用户/云屏蔽和高赞标记 | 可作为后续增强，但云屏蔽是基于返回权重过滤，不是本地 AI 推理 | 不能把新增类型过滤宣称为完整支持 B 站全部弹幕行为 |

实测对照（同一匿名网络、BV1xx411c7Xg / cid 3659795，约 20 分钟）：XML 共 3600 条，各六分钟区间为 3338/175/69/18；分段接口四段为 2963/1706/1325/326，共 6320 条。第一段并非分段接口更多，后段覆盖改善明显。单片源样本不能推出所有视频都增加同一比例，也不是全部历史弹幕或唯一条目集合的证明。

实施顺序调整为：数据覆盖与生命周期 → 轨道密度/拥塞策略 → 播放中即时设置 → 旧浏览器与高密度性能验证。原型已有外观选项与类型支持可保留，但不应在完成这些检查前当作最终方案发布。
