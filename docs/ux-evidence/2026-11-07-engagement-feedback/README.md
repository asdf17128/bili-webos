# 赞／币／收藏：明确操作结果

用户反馈按下互动按钮缺少明显结果。此前主要依靠计数与短提示，聚焦样式还会盖住已操作的颜色。本轮增加等待进度、成功时图标轻弹与结果文字；已点赞／已收藏持续显示粉色状态及勾，投币持续显示已投 1／2 枚。取消、失败各有提示，失败不增加计数。焦点和按钮位置保持稳定，减少动态效果模式关闭动画。

单项操作和长按三连共用请求锁，等待中连续确认不会重复提交。初次关系查询、重试与三连后校准都检查操作版本；新的取消或切换不会被旧响应覆盖。关系未知时先读取，读取失败不发互动写请求，退出后不再更新反馈。

## 本地验证

- 新增互动专项 **15/15 通过**：[逐项结果与源码哈希](engagement.json)。覆盖成功／取消、三种失败重试、投币上限、收藏夹读取失败、单项与三连互斥、初次及校准响应迟到、关系未知、退出后的响应，以及有效番剧 aid 的点赞。
- 原有控制栏回归 **54/54 通过**：[逐项结果](controls-regression.json)。覆盖默认播放焦点、三组布局、设置、短按／长按、透明度、推荐卡片与动画、字幕避让和粉丝淡出；两组结果的生产源码哈希均与最终文件一致。
- 已查看成功、等待、失败和 720p 大字号评论侧栏截图。角标不被裁剪、不碰相邻图标；当前焦点的说明行显示结果时不重复显示相同 toast。
- 生产构建、7 个 JavaScript 产物的 ES2016 解析、三连状态 10 项检查及中／英／西翻译检查通过。[构建日志](build.log)、[检查摘要](checks.json)。

使用真实 React 与浏览器受信输入，媒体和 API 均为合成夹具，外部请求全部拦截。没有操作电视、真实账号或发布；不将浏览器语法解析视为旧版 webOS 或真实播放验收。
