# #66 弹幕功能对照与补齐

需求来源：[有关增加更多弹幕自定义设置的建议 #66](https://github.com/asdf17128/bili-webos/issues/66)。2026-11-06 重新读取原文，无追加评论。以下按 issue 明确列出的功能验收，不把参考 Android 工程的所有功能当作已实现。

## 功能对照

| 原始需求 | 当前实现 | 本地检查 |
|---|---|---|
| 透明度 | 不透明度 25 / 50 / 75 / 100% | 每档实际样式、保存与重启恢复 |
| 字体大小 | 小／标准／大／特大，0.8 / 1 / 1.3 / 1.6 | 相同 28px 源弹幕实际为 22 / 28 / 36 / 45px |
| 字体粗细 | 400 / 600 / 700 | 每档实际计算样式、保存与恢复 |
| 描边 | 关闭／标准／加粗 | 关闭无阴影、两种描边计算样式不同 |
| 屏占比 | 顶部 1/4、1/2、3/4、全屏 | 固定底部弹幕始终位于所选区域内，区域变化生效 |
| 弹幕密度 | 同屏上限 12 / 24 / 48，联动轨道间距 | 密集输入实际达到三档上限，有界节点和测量缓存 |
| 滚动速度 | 慢／标准／快，0.75 / 1 / 1.5 | 相同文字的实际动画时长按速度反比变化 |
| 固定／滚动／彩色类型 | 顶部固定、底部固定、普通与反向滚动、源颜色；分别开关过滤 | 类型过滤、颜色过滤、区域边界与关闭重开 |
| 弹幕较少 | 点播分段获取、下一段预取、有限缓存、拥塞短暂重试 | 分段失败回退、跳转隔离、边界保留、重复去除与晚时段查询 |

已有设置入口、点播播放中设置和分段弹幕实现保留。本次补齐的是**直播播放中设置入口**：同一面板调整外观、区域、密度、速度和滚动开关，立即应用到实际直播弹幕，自动保存；不重取流，不重建聊天订阅，关闭后恢复遥控焦点。直播当前只接收白色滚动文本，面板及预览只展示适用选项；点播的固定、彩色和人物遮罩偏好保持原值。直播与点播共用外观偏好。

## 验证边界

所有测试都在本地。浏览器使用真实 React、样式、遥控键盘与指针交互；外部账号和视频接口使用合成数据，直播播放事件及聊天回调受控。测试验证的是设置、渲染、请求次数和生命周期，不证明电视解码、真实直播网络或 4K 性能。本轮没有操作电视、发包、发布或关闭 issue。

字幕、普通视频界面字号与弹幕设置独立。高级定位／脚本弹幕没有新增执行支持；直播固定／彩色模式、历史弹幕查询、关键词／用户／云屏蔽及高赞标记不属于此次 issue 明确列出的设置验收。实验性人物遮罩另见[专项证据](../2026-11-06-person-mask-optimization/README.md)，源数据漏人的限制仍存在。
