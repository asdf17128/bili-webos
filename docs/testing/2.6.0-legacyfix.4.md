# 2.6.0 legacyfix.4 — 旧电视控制栏对照测试

- 控制栏按钮改为即时高亮，取消焦点切换时的缩放，让选中状态更直接。
- 简化控制栏视觉效果，保留清楚的选中边框和操作反馈。
- 保留推荐区域展开动画、两排视频卡片，以及上一测试包的快进和预览图改进。

这是用于验证旧电视操作延迟的独立测试包，实际效果需要原设备确认，不进入 Homebrew 或正式版自动更新。

## 安装与对比

下载 Assets 中带 `legacyfix.4` 的 IPK，覆盖安装即可，不用卸载或退出账号。设置 → 关于确认 **2.6.0 legacyfix.4**。

请与 legacyfix.3 使用同一视频、画质及弹幕设置对比：

1. 播放时，每隔约半秒短按一次左右键，观察按钮高亮是否更及时、是否仍有突然停顿。
2. 持续长按 3–5 秒，比较按钮切换与进度条移动。
3. 暂停视频后重复前两项，说明延迟是否明显减轻。
4. 观察亮色画面上的标题、按钮与数字是否仍清楚，推荐区展开是否正常。

如果方便录像，请同时拍到遥控器按键和电视画面，便于区分按下到响应的延迟与画面更新不均匀。不需要提供账号凭据。

无需重复测试已确认恢复的登录功能。需要回退时，可覆盖安装 legacyfix.3。本测试包不宣称已解决原设备上的延迟。
