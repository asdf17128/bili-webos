# 2.6.0 legacyfix.7 — 播放中控制栏对照测试

- 继续减少播放控制栏的常驻绘制开销，保留现有布局、选中效果和推荐区展开动画。
- 补充播放／暂停时的响应诊断，帮助区分按键处理与界面更新的延迟。
- 包含此前快进、预览图优化及紧凑弹幕行间距设置。

这是独立测试包，尚未确认解决旧电视的间歇停顿，不进入 Homebrew 或正式自动更新。

## 安装与复测

覆盖安装 Assets 中带 legacyfix.7 的 IPK，设置 → 关于确认版本，无需退出账号。

继续使用之前的视频、画质和关闭弹幕设置：播放中短按、长按左右键，然后暂停后重复，最后恢复播放比较。也请试一次推荐区展开和收起，观察动画是否正常。

如果仍卡，请在这次操作后直接返回设置 → 网络诊断，保留 `controls-playing` 和 `controls-paused` 两行，不要先换片或重启。新版增加 `timerMax`、`timers`、`handlerMax` 字段；没有某项时也请原样反馈。

需要回退时可覆盖安装 legacyfix.6 或 legacyfix.5。
