# 透明控制栏文字可读性

控制栏标题用 700 字重，UP／粉丝数、按钮标签、时间和浏览提示用 600 字重及白色；以四向 1px 深色文字阴影形成细边，再加短阴影。图标增强小范围投影，选中按钮仍用浅底深字并去掉阴影。推荐卡片继续共用列表页样式，透明背景渐变不变，没有加入 backdrop-filter。

同一合成明／暗背景前后截图已人工查看：明亮画面中文字边界更明确，暗画面不增加大块背景。修改前 5 个视觉／透明度基线通过；修改后相关回归 15/15，包括 1080p、720p、大字号、长 UP 名称、字幕避让、评论侧栏、卡片样式一致、粉丝数淡出连续性及两种纹理背景的透明度像素检查。生产构建通过。

透明度指标并非文字 WCAG 对比度，也不证明全部视频场景或真实电视可读性；本轮仅本地验证，未安装电视、未发布。
