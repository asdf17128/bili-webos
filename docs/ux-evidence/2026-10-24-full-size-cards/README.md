# 正常视频卡片与两排展开

用户澄清：推荐卡片应保持列表页规格，通过控制栏向上延伸容纳两排；撤回的 2.5.0 横向小卡并不符合要求。

实现直接复用列表卡片的样式与文字结构，保留 16:9 封面、两行标题、UP／播放信息和焦点边框；按真实卡片高度与行距计算两排容器高度。面板仅做 transform 动画，同一组卡片一直存在。小屏大字号允许上方控制区移出视口，返回时恢复可见焦点。浏览推荐期间隐藏字幕，收起恢复，避免顶部裁切。

验证：
- 撤回版正对照 0/1：未使用正常列表卡片结构。
- 首轮 32/36，保留原结果：滚动仍沿用旧行距，已改按实际布局测量；原断言要求小屏完整控制区也在屏幕内、展开字幕仍在标题上方，与两排大卡的空间需求冲突，改为检查两排及标签完整、返回控制焦点可见、字幕隐藏后恢复。没有把首轮失败记作通过。
- 最终控制栏回归 37/37；包括与同宽列表卡片的计算样式对照、1080p／720p 大字号两排边界、遥控／滚轮滚动、连续节点、六倍 CPU 限速、反向／减少动态效果、字幕恢复与评论侧栏。源码哈希前后一致。
- 生产构建通过；保留既有的大块 bundle 提示。

截图及 API／媒体均为合成夹具，不是真机或真实播放画面。CPU 限速不能证明电视实际帧率。本轮未部署电视、未发布，2.5.0 仍为撤回草稿。
