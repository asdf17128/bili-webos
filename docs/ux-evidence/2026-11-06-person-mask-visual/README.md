- [修改前切镜问题](before-cut.png)：人物近景出现后，文字仍横穿额头、眼鼻和左半脸。日志依旧为 active、failures=0。
- [修改后脸部边缘](face-edge.png)：脸中央大部分可见，但左脸、鼻嘴附近仍有文字侵入。因此没有宣称同步改动已解决所有遮挡问题。
- [暂停到 7.75 秒](source-gap.png)：等待更新后仍整脸覆盖文字。原始遮罩从 7,682 ms 起连续多帧只有全背景矩形，没有人物透明洞。这是源遮罩没有提供该人物轮廓，不能靠重复使用前一场景的轮廓解决。

片段来自同一公开视频和 CID，但仅是短样本；未验证其他视频、多人、直播或原生 webOS 视频平面。密集文字是用于暴露边缘的测试覆盖层，不是实际源弹幕。

## 本轮代码改动

- 从每 100 ms 绘制改为使用 `requestVideoFrameCallback` 的媒体时间；旧浏览器使用 `requestAnimationFrame`。100 ms 仍负责分段加载、暂停和原生视频不提供帧回调时的兜底。
- seek 开始取消旧回调，seek 完成后换代际并重新注册。关闭、切源后迟到的帧回调不能重新写入遮罩。
- 相同 SVG 与布局不重复解析和设置 CSS；增加实际选中遮罩帧时间与媒体时间的诊断字段。
- 测试脚本增加播放中定期截图，明确将运行检查与人工视觉结论分开。

这些改动减少粗粒度轮询的同步限制，**未证明边缘和切镜问题全部解决**。另观察到样本部分 rVFC 时间与源遮罩时间存在约 2 ms 的相位差，严格取此前帧时可能落后约 38 ms；视频片段起始 PTS 为 40 ms。尚未确认是源时间量化还是片段封装时基，未在产品中硬编码偏移。后续需用未重封装媒体和另一份样本对照定位，不能用这个样本的偏移推广到所有视频。
