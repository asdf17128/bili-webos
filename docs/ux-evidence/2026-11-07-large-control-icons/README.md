# 大图标与清晰焦点：本地验证

主栏保持左侧互动、中间播放、右侧评论／设置的顺序，打开时默认聚焦播放／暂停。普通图标由 28px 提升至 40–44px，播放图标为 48–52px；取消九个常驻文字标签，保留无障碍名称和固定的焦点说明行。赞／币／收藏／评论计数保留，过长数字在按钮内省略，聚焦说明显示完整值。

聚焦圆底使用白色、深色图标、蓝色外圈与深色分隔边，轻微放大。底色与图标色立即切换，仅缩放过渡，避免颜色插值中途对比不足。计数不随焦点移动；720p 评论窄栏的图标中心和三组位置保持对齐。金币保留已有黄白图样。

长按三连的进度环改为围绕圆形图标，仍保留短按点赞、取消长按和两秒三连逻辑。成功反馈只轻弹图标，不再放大整颗按钮；窄栏缩放受限，减少动态效果模式关闭反馈动画。

## 验证结果

- 大图标布局和圆形长按环完成后，现有控制栏完整套件 **54/54 通过**，含三组顺序、默认焦点、明暗画面、720p／1080p、大字体、评论、两排推荐与动画、字幕避让、粉丝淡出、互动和设置。[报告摘要](controls-layout.json)保留全部用例结果与当时源码哈希。
- 最后仅收紧三连成功反馈的 CSS，相关短按／长按、赞币藏／稍后看、窄栏及减少动态效果专项 **7/7 通过**。[最终报告摘要](controls-feedback.json)的起止源码哈希稳定且与最终代码一致；两轮之间只有 `playerControls.css` 变化，见[检查记录](checks.json)。没有把最后补修前的整套结果写成补修后的重跑。
- 使用实际 CSS 在 720p、1.4 倍字号、420px 评论栏条件下采样成功动画，普通／减少动态效果各 32 帧：按钮及计数位移均为 0，计入焦点外圈后圆底仍有间距；减少动态效果下动画名为 `none`。[几何采样](success-animation-geometry.json)。这是本地布局采样，不是电视呈现帧率。
- 生产构建通过，[构建日志](build.log)；7 个 JavaScript 产物按 ES2016 解析通过。
