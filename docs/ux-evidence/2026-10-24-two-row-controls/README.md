# 两排推荐与连续动画（本地验证）

用户在电视上指出旧 FLIP 动画会先裁掉一截卡片，随后要求电视留作观看、后续只做本地测试，并要求两排视频与更顺滑的滚动。

最终实现保留同一个四列网格，使用封面在左、标题在右的紧凑卡片，同时展示两排。网格与面板布局高度不变，展开/收起只执行整块 transform；预览与展开不再替换卡片。滚轮每档一排，小幅输入累计并限频；方向键与滚轮的逐排浏览使用平滑滚动，减少动态效果偏好关闭位移与滚动动画。

- 卡片节点连续性：旧版 0/1，新版通过。
- 两排完整展示及布局高度恒定：旧版 0/1，新版 1080p 与 720p 大字号通过。
- 逐排动画：旧版 0/2，新版方向键与滚轮通过。
- 最终控制栏套件 36/36，源码哈希前后一致；包括六倍 CPU 限速下布局稳定、反向输入、小幅滚轮、字幕、画质、评论栏、大字号、亮暗纹理与未知粉丝数等。
- 截图为合成场景及虚构账号/视频，已人工查看；真实媒体与外部 API 使用隔离替身。CPU 限速不等于旧电视硬件，rAF 不等于合成器呈现帧率。
