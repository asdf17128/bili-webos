# 赞／币／收藏：明确操作结果

用户反馈按下互动按钮缺少明显结果。此前主要依靠计数与短提示，聚焦样式还会盖住已操作的颜色。本轮增加等待进度、成功时图标轻弹与结果文字；已点赞／已收藏持续显示粉色状态及勾，投币持续显示已投 1／2 枚。取消、失败各有提示，失败不增加计数。焦点和按钮位置保持稳定，减少动态效果模式关闭动画。

单项操作和长按三连共用请求锁，等待中连续确认不会重复提交。初次关系查询、重试与三连后校准都检查操作版本；新的取消或切换不会被旧响应覆盖。关系未知时先读取，读取失败不发互动写请求，退出后不再更新反馈。
