# 智能防挡人物实验版验证

版本：`2.5.2 danmaku-mask.1`，未发布、未安装到电视。开关默认关闭，在全局弹幕设置或点播控制栏的弹幕设置中启用。

## 实现与数据来源

复用当前视频 `player/wbi/v2` 返回、CID 匹配的 `dm_mask.mask_url`；不在电视运行人像识别，也不读取原生视频平面的像素。格式参考 [webmask-renderer](https://github.com/andrewvy/webmask-renderer) 的记录及真实文件独立实现；解压使用 pako 2.1.0，随包附带其许可声明。

只允许 HTTPS 的 Bilibili `cmaskboss/*.webmask` 地址。按 Range 获取索引、当前段和下一段，最多两段缓存；压缩/解压/帧数/单帧/SVG 节点均有上限。远端 SVG 只允许几何形状与有限属性，拒绝脚本、事件处理器、外链、图片、CSS、DOCTYPE 和实体声明。

遮罩仅作用于弹幕层，每 100 ms 检查播放时间；不影响视频、字幕与控制栏。按实际视频比例定位，保留黑边区域。跳转同步清除旧遮罩，暂停不重复更新同一帧，超过 250 ms 的旧帧不继续使用。关闭/退出/切换来源释放计时器与缓存并隔离迟到响应。无数据、时间段空缺、不支持或失败均保留普通弹幕；时间段空缺不会一直显示加载中。

## 本地验证结果

1. **格式与预算 6/6**：基础 4 项加两份真实文件，分别解析 31 段/9,360 帧和 22 段/5,308 帧。验证重复时间戳、带换行 Base64、损坏输入、索引/时间/长度边界与 gzip 超限保护。
2. **浏览器遮罩 9/9**：从截图实际像素验证人物区域透明、周围弹幕保留、黑边不误裁；验证前后跳转、过期帧状态、关闭、迟到响应、失败不循环重试、SVG 限制、Luna Range/base64 路径和真实 SVG。6 倍 CPU 节流数据见 [原始结果](pixel-tests.json)，不换算为电视性能结论。
3. **真实视频解码 + 匹配遮罩**：公开样本 `BV1GJ411x7h7` / CID `137649199` 的前 8 秒片段，在本地实际解码，1/3/6 秒均匹配遮罩且没有页面错误。画面使用密集测试文字覆盖，以便检查人物轮廓；不是实际源弹幕密度。见 [3 秒截图](real-frame-3.png) 和 [数值记录](real-video.json)。没有把媒体 URL、账号凭据或完整视频保存到仓库。
4. **播放器集成**：验证当前 CID 校验、缺失遮罩、服务失败降级、控制栏即时设置和焦点恢复；最后一次针对性回归 4/4。
5. **既有功能回归**：完整门禁各组通过，包括生产 ES2016 构建、Node 0.12/8 服务兼容、通用 UX 74/74、推荐菜单 62/62、账号修复 UI 26/26、播放加载 84/84、控制栏 42/42、分段弹幕 7/7、弹幕渲染 13/13，以及直播、CDN、诊断等。首轮通用 UX 的彩色弹幕导航写死了选项数；新增开关后改为验证实际选中标签，并补充新开关保存断言，再跑 74/74 通过。后续“空缺帧”状态补丁已重跑遮罩浏览器、真实视频、播放器集成及生产构建。

真实片段可视化测试起初使用不完整的本地 HTTP Range 实现，导致媒体 seek 被限制在起点；修正测试服务后通过。另一个新增空缺状态补丁的 seek 回调曾引用错误变量，被页面异常断言捕获并修正；最终浏览器记录无页面异常。

## 复跑
