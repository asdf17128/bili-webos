# 2.6.0 legacyfix.2 — 旧电视控制栏性能测试

保留 legacyfix.1 的播放恢复修复，减少播放中操作控制栏时的不必要刷新，重点改善切换按钮、长按方向键时的响应。控制栏收起后减少后台界面刷新，保留原有按钮、推荐卡片和动画。

这是独立测试包，不进入 Homebrew 或正式版自动更新。起播耗时仍需另外排查；尚未确认报告者旧电视上的实际改善幅度。

## 安装与复测

1. 下载 Assets 中带 `legacyfix.2` 的 IPK，覆盖安装，无需卸载、退出账号或重建设备标识。
2. 设置 → 关于确认显示 **2.6.0 legacyfix.2**。
3. 用之前卡顿的同一视频、相同画质和弹幕设置，观察控制栏左右切换、长按方向键、快进，以及推荐区展开／收起。
4. 请反馈之前的 1–2 秒延迟是否缩短、长按是否仍会卡住。如果仍明显卡顿，可对比暂停后、关闭弹幕后是否改善，并附 BV、所选画质、电视型号；这些对照用于定位，不要求长期关闭功能。
5. 如出现播放失败，请在换片或重启前生成新版网络诊断。

可覆盖安装 legacyfix.1 或 2.6.0 正式包回退。

## 本地验证

- 控制栏回归 71/71，另补测连续 20 次方向键、隐藏时停止刷新和重新打开后的进度同步。
- 续播 19/19，前后切换 20/20。
- 单元测试 249 通过，0 失败，1 项可选测试跳过。
- 生产构建及 Chrome 53 语法兼容检查通过。
- 降速模拟只证明刷新开销减少，不代表旧电视硬件实测。未操作电视。
