## 服务、中继与开发桥

未发现需要中止冻结候选长播的严重回归。

- 中继失败先设置 ended 并释放 current，再清定时器和销毁资源；error/close/send 的交叠回调不能重复安排 retry。
- 旧连接 open/message/error/close 受连接身份与存活状态约束，迟到获得的 request socket 会被销毁。
- 每个中继的 Agent/request/socket 有独立所有权，不操作媒体 keep-alive 池；stop 同步取消重试、握手、认证和心跳定时器。
- 认证和心跳分别判断。安静房间由心跳维持；持续故障按退避低频探测，退出后停止。
- 服务按订阅 token 清理，最后一个监听者退出才停止 relay；DEV 桥使用唯一 token 和幂等 close/error 取消。

该复核没有重跑测试。实际旧 WS socket 实验、本地有界故障专项和 C4 真实心跳恢复证据另存；不能据此声称已穷尽所有平台 TLS 行为。
